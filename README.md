# Portal Rendición de Cuentas 2025 - Hospital Gonzalo Contreras E.S.E.

## Ejecutar local
```bash
npm install
npm run dev
```

## Publicar en Vercel
1. Crear repositorio nuevo en GitHub.
2. Subir esta carpeta completa.
3. En Vercel: Add New Project > Importar repositorio > Deploy.

## Preguntas ciudadanas
El formulario usa FormSubmit con destino configurado en `src/main.jsx`:

```js
const EMAIL_SISTEMAS='lider.sistemas11@gmail.com';
```

Cambiar ese correo por el correo institucional de sistemas si se requiere.

Además, cada pregunta queda guardada en el navegador en el Panel preguntas y se puede exportar en CSV.

## Nota
Se retiró la franja azul superior gov.co según la solicitud. El diseño conserva una estética institucional limpia, responsive y alineada al manual de marca del Hospital.
